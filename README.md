# MiguelAlfonsoLaraRichter

Práctica básica de Git con código de ejemplo para ESP32 (Arduino / PlatformIO en Visual Studio Code).

## Estructura del proyecto

- `src/main.cpp`: Código fuente de ejemplo para encender y apagar el LED integrado (GPIO 2) del ESP32 con salida por monitor serie a 115200 baudios.
- `platformio.ini`: Configuración de PlatformIO para la placa `esp32dev`.

## Ramas

- `main`: Rama principal con el código fuente.
- `miguelrepasogit`: Rama personal con el mismo código fuente.
